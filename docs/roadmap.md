# Roadmap

1. Extend the implemented deterministic models, canonical wire/recovery mutation,
   coverage-guided fuzzing, filesystem interruption, and commit-pinned local
   release qualification with broader command models plus repeated remote and
   supported-host campaigns.
2. Extend the implemented stable-topic and separately negotiated rename
   substrate only through separately decided move, merge, resolution, and
   conversation-collection laws.
3. Extend the qualified local exact-record offline backup/restore mechanism with
   real device/power-loss campaigns, authenticated/encrypted transport,
   retention and rollback policy, then qualify upgrade/rollback and an
   additional physical store only when a deployment profile requires broader
   claims.
4. Extend the implemented exact key/scope/revision operator authority and Aegis
   decision-correlation evidence only with a separately defined coordinated
   recovery protocol; the current mechanism is explicitly non-atomic.

Agent harness selection, prompting, retries, and execution remain out of scope.
