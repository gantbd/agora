## Verification gates

`make check` runs fuzz corpus/toolchain-contract validation, formatting, Clippy
with warnings denied, all tests offline, doctests, and warning-denied
documentation. This establishes only the in-process
core, service recovery, receipt-gated store boundary, and private local transport
composition exercised by those checks. It establishes only the explicitly
bounded local Unix storage and sequential socket mechanisms, not hardware
power-loss behavior, network-filesystem semantics, network transport security,
concurrent operational daemon lifecycle, push delivery, distributed ordering, or connector
behavior.

The external Moira qualification projects an unacknowledged `MessageAccepted`
event as a participant-neutral read-only fact, then requires explicit Moira
admission. Its restart, eviction, replay, and conflict evidence is maintained by
Moira's own gate; it is not part of Agora's `make check`.
